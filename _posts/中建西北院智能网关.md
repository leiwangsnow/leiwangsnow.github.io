> **面向建筑物联网场景的边缘智能网关**
>
> RK3506 + 433MHz LoRa + 4G / Ethernet + MQTT  
> 自有 LoRa 通信协议，连接现场设备与上层平台。

---

## 产品简介

这是面向建筑机电、HVAC、楼宇物联网等场景设计的一款边缘智能网关。

网关以 **RK3506** 为核心计算平台，通过 **433MHz LoRa** 接入现场无线设备，在网关侧完成设备接入、数据采集、状态管理与控制指令处理，并通过 **4G / Ethernet** 将数据进一步接入上层平台。

产品采用自有 LoRa 通信协议，围绕实际建筑物联网应用进行设计和持续迭代。

## 核心能力

### 01 · 自有 LoRa 协议

围绕建筑物联网业务场景设计自己的 LoRa 通信协议。

通过自有协议实现现场节点与网关之间的数据交互，为后续设备扩展和产品迭代提供统一的无线通信基础。

### 02 · RK3506 边缘计算

网关采用 RK3506 Linux 平台。

在现场完成设备接入、状态管理、数据处理以及控制指令等边缘业务，减少所有数据都依赖云端处理的方式。

### 03 · 433MHz 无线接入

采用 433MHz LoRa 无线通信方式连接现场节点。

适用于建筑内部传感器、HVAC 面板以及其他低功耗物联网设备。

### 04 · 4G + Ethernet

网关支持现场有线网络以及 4G 蜂窝网络。

根据项目现场网络条件选择合适的上行方式，实现网关与远端平台之间的数据连接。

### 05 · MQTT 北向通信

网关通过 MQTT 与上层业务平台进行数据交互。

目前规划的数据类型包括：

```text
Gateway Status
       │
       ├── Device Status
       │
       ├── Telemetry
       │
       └── Command
```

## 产品组成

### 网关

**RK3506 + LoRa + 4G**

负责现场无线设备接入、协议处理和边缘业务运行。

### LoRa 节点

基于 ESP32-S3 等 MCU 平台构建现场设备。

可用于：

- HVAC 控制面板
- 温湿度采集
- 环境监测
- 房间设备
- 其他建筑物联网节点

### 上层平台

通过 MQTT 接收网关上报的数据，并向网关下发设备控制指令。

后续可以进一步连接：

- 楼宇管理平台
- 能源管理平台
- HVAC 管理平台
- 数字孪生平台
- 其他物联网业务系统

## 应用场景

### 建筑 HVAC

通过 LoRa 将房间控制面板、环境传感器等设备接入网关，实现建筑 HVAC 设备的统一联网。

### 楼宇物联网

一个网关可以连接多个现场无线节点，减少传统有线布线带来的施工复杂度。

### 能源管理

现场设备的数据通过网关汇聚后上传平台，为建筑能源数据采集和分析提供基础。

### 数字孪生

网关作为现场设备与数字孪生平台之间的边缘连接设备，将真实建筑设备状态接入数字化系统。

## 写在最后

建筑物联网不是简单地把设备连接到网络。
